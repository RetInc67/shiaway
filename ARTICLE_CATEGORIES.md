# ShiaWay — статьи и категории

Обновлённая версия добавляет:

- отдельный интерфейс «Книги / Статьи» в Worker CMS;
- категории и вложенные подкатегории статей;
- статьи как файлы внутри категорий;
- выбор категории при создании/редактировании статьи;
- отдельную страницу чтения `article.html?id=...`;
- новый поиск и файлово-папочную навигацию на сайте;
- API `/api/article-categories`, `/api/articles` и `/api/articles/:id`.

## D1
Отдельный SQL-файл для миграции не нужен: Worker автоматически создаёт таблицы `article_categories` и `article_category_links` при первом запросе и переносит старые статьи без категории в папку «Без категории».

Перед публикацией Worker проверь, что к нему привязана существующая D1 с таблицей `articles`.

## Сайт
Загрузить содержимое папки `shiaway` на текущий статический хостинг. Новый файл `article.html` должен находиться рядом с `index.html`.
